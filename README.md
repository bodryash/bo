# Поток — студенческая соцсеть МГУ в Telegram

Мини-приложение Telegram. У каждого факультета своя лента, и есть общая лента
всего университета. Вход через Telegram, регистрации нет.

## Что внутри

| Что | Зачем заходить каждый день |
| --- | --- |
| **Лента факультета и всего МГУ** | Переключатель сверху; новое и «горячее» (лайки и комментарии, делённые на возраст поста) |
| **Рубрики** | Общее · Учёба · Подслушано · События · Барахолка · Бюро находок · Жильё |
| **Подслушано** | Всегда анонимно. В комментариях — «Аноним 1», «Аноним 2»: один человек под одним номером внутри поста, автор помечен |
| **События** | Дата и место, отдельная сортировка «скоро»; ближайшие события МГУ на вкладке поиска |
| **Барахолка, находки, жильё** | Цена или «Даром», отметка «продано / нашлось» — пост гаснет, но остаётся |
| **Фото и опросы** | До 6 фото, сжатие на телефоне до ~300 КБ; опрос до 6 вариантов, один голос |
| **Комментарии** | Ответ цитатой, как в Telegram; анонимный режим — кнопка с маской |
| **Уведомления** | Вкладка «Ответы» со счётчиком и сообщение от бота с кнопкой «Открыть» |
| **Профиль** | Факультет, курс, о себе; «Написать в Telegram», если человек не скрыл ник |
| **Поиск** | Люди и посты, без учёта регистра и «ё» |
| **Поделиться** | Ссылка вида `t.me/бот/приложение?startapp=p12` сразу открывает пост |

## Из чего состоит

| Что | Где |
| --- | --- |
| Страница приложения — HTML, CSS и JS-модули без сборки | `public/` |
| API, бот и фото — один Cloudflare Worker | `src/` |
| Схема базы D1 | `schema.sql` |
| Сквозная проверка API | `tests/smoke.mjs` |
| Подпись initData для локальной работы, наполнение базы | `tools/` |

Воркер раздаёт и страницу (папку `public` через assets), и API на том же
адресе. Одна команда `npx wrangler deploy` выкладывает всё, CORS не нужен.

- `/api/*` — API, каждый запрос подписан Telegram (`Authorization: tma <initData>`).
- `/img/*` — фото (из канала-склада в Telegram или из R2), кэшируются навсегда: имя файла случайное и не меняется.
- `/tg` — вебхук бота.

Справочники факультетов, рубрик и лимитов лежат в `public/js/data.js`. Этот файл
импортирует и приложение, и воркер, поэтому список на экране и проверка на
сервере не могут разойтись.

## Первый запуск в бою

Выкладку делает GitHub Actions (`.github/workflows/deploy.yml`) при каждом
push в ветку `potok`. Сценарий создаёт базу, если её нет, обновляет
таблицы, выкладывает воркер и настраивает бота: вебхук, кнопку «Поток»
в меню, описание и команды. Руками нужно сделать то, что требует вашего
аккаунта, и только один раз:

1. **Бот.** @BotFather → `/newbot` → сохраните токен. Откройте нового бота
   и нажмите **Start**, иначе он не сможет вам писать.
2. **Токен Cloudflare.** dash.cloudflare.com → My Profile → API Tokens →
   Create Token → шаблон **Edit Cloudflare Workers**. Добавьте строку
   **Account → D1 → Edit**, затем Continue → Create. Сохраните токен.
3. **Секреты в GitHub.** Репозиторий → Settings → Secrets and variables →
   Actions → New repository secret. Нужны четыре:

   | Имя | Что вставить |
   | --- | --- |
   | `CLOUDFLARE_API_TOKEN` | токен из шага 2 |
   | `CLOUDFLARE_ACCOUNT_ID` | id аккаунта: Workers & Pages → справа «Account ID». Если аккаунт один, можно пропустить |
   | `BOT_TOKEN` | токен из шага 1 |
   | `ADMIN_IDS` | ваш id в Telegram (у @userinfobot); нескольких модераторов — через запятую |

4. **Запуск.** Actions → «Выложить Поток» → последний запуск → **Re-run all
   jobs**. Или просто сделайте push. В итоге запуска будет адрес
   приложения.
5. **Канал для фото** (шаг «Фото» ниже).

Короткое имя приложения из `/newapp` в @BotFather не обязательно: без него
ссылка «поделиться» открывает пост через `/start` в боте. Если хотите
ссылки вида `t.me/бот/app?startapp=p12`, сделайте `/newapp` с адресом
приложения и укажите короткое имя в `APP_NAME` в `wrangler.toml`.

Выложить вручную, без GitHub: `npx wrangler d1 create potok` (id — в
`wrangler.toml`), `npm run db:remote`, `npm run deploy`,
`npx wrangler secret put BOT_TOKEN`. Потом один раз настройте бота:
`curl -X POST <адрес>/setup -H "authorization: Bearer <токен бота>"`.

### Канал для фото

Создайте **закрытый** канал (например, «Поток — фото») и добавьте туда бота
**администратором** с правом публиковать сообщения. Добавлять должен
модератор из `ADMIN_IDS`. Бот сам запомнит канал и напишет «Готово».
Проверить можно командой `/media`.

## Фото

Фото хранятся в Telegram. Воркер отправляет каждое фото файлом в
канал-склад, без пересжатия, и запоминает его номер в Telegram. Когда фото
нужно показать, воркер забирает файл у Telegram и отдаёт его, а Cloudflare
кэширует навсегда: имя файла случайное и не меняется. Так что повторные
показы не доходят ни до базы, ни до Telegram.

- Это бесплатно, объём не ограничен, карта не нужна. R2 требует привязать
  карту даже на бесплатном тарифе.
- Ссылки Telegram на файлы содержат токен бота, поэтому наружу не уходят:
  приложение видит только `/img/<случайное имя>.jpg`.
- Фото, которые так и не попали в пост, через сутки удаляются и из базы,
  и из канала.
- **Не удаляйте канал и не убирайте из него бота.** Иначе старые фото
  перестанут открываться. Если бота всё-таки уберут, он предупредит
  модераторов.

Если есть зарубежная карта и хочется хранить фото у Cloudflare,
раскомментируйте R2 в `wrangler.toml`. Воркер сам начнёт класть фото туда.

## Сколько выдержит бесплатный тариф

Ориентир — **1000–1500 человек в день**. Раньше всего кончаются два
суточных лимита: 100 тыс. запросов к воркеру (один человек тратит около 60,
фото тоже идут через воркер) и 5 млн прочитанных строк D1 (около 3–4 тыс.
на человека). Страница, стили и скрипты в лимит не входят.

При превышении приложение не замедляется, а перестаёт отвечать до 03:00 по
Москве, когда лимиты обнуляются. Тариф Workers Paid за 5 $ в месяц хватит
примерно на весь МГУ (5–10 тыс. человек в день), но оплачивается только
зарубежной картой.

Из России Cloudflare с июня 2025 года режут: без VPN грузятся только первые
~16 КБ ответа. Ленте и фото этого мало. Перед большой рассылкой проверьте
на знакомых без VPN и с прокси внутри Telegram.

## Модерация

Вся модерация идёт в личке с ботом. Команды принимаются только от `ADMIN_IDS`.

- **Три жалобы от разных людей** скрывают пост или комментарий. Модераторам
  приходит карточка: текст, автор (даже анонимный), причины жалоб. На ней
  кнопки «Вернуть», «Удалить», «Удалить и бан на 7 дней». Решение дописывается
  в карточку, чтобы второй модератор не взялся за уже разобранное.
- `/hidden` — всё, что сейчас скрыто жалобами.
- `/who p12` · `/who c34` — карточка поста или комментария с кнопками.
- `/del p12` · `/restore p12` — удалить или вернуть.
- `/ban №5 7 спам` — бан на 7 дней с причиной; без числа — навсегда.
  Человека можно указать как `№5`, `@ник` или `p12` (автор поста).
- `/unban №5` · `/stats` — сводка за сутки и неделю.
- `/media` — где хранятся фото и сколько их.

Модератор в самом приложении видит у чужих постов и комментариев пункт
«Удалить (модератор)».

**Анонимность.** Автор анонимного поста или комментария вообще не покидает
воркер: в ответах API нет ни имени, ни id, ни намёка в счётчиках профиля.
Узнать автора может только модератор через бота, и только когда нужно
разобрать жалобу.

## Лимиты

| Что | Сколько |
| --- | --- |
| Посты | 15 в сутки, из них анонимных — 5 |
| Комментарии | 150 в сутки |
| Жалобы | 30 в сутки |
| Фото | 60 загрузок в сутки, до 6 на пост, до 3 МБ |
| Уведомления от бота | не чаще раза в 5 минут; остальное видно на вкладке «Ответы» |

Лимиты записаны в начале `src/posts.js`, `src/comments.js`, `src/media.js`,
`src/moderation.js` и `src/notify.js`.

## Разработка

Локально вместо настоящего Telegram работает его имитация
(`tools/mock-telegram.mjs`). Она хранит отправленные фото, отдаёт их обратно
и записывает всё, что бот «отправил». Её адрес уже прописан в
`.dev.vars.example`.

```bash
cp .dev.vars.example .dev.vars   # тестовый токен, ADMIN_IDS, адрес имитации
npm run mock                     # имитация Telegram, окно 1
npm run db:local                 # таблицы в локальной базе
npm run dev                      # http://127.0.0.1:8787, окно 2
```

В третьем окне:

```bash
npm run smoke                    # 23 сквозные проверки: API, фото через Telegram, бот, самонастройка
node tools/seed.mjs              # 6 человек, 8 постов, лайки, опрос, комментарии
```

Тесты сами подключают канал-склад от имени модератора. Если нужно
посмотреть ленту с фото без тестов, сначала выполните `npm run smoke`.

Вне Telegram приложению нужна подписанная строка входа. Её печатает
`node tools/sign.mjs 9001 Аня`. Откройте
`http://127.0.0.1:8787/#dev=<строка>`, и вы войдёте как Аня из
`tools/seed.mjs`. Такая подстановка работает только на localhost; в бою
подпись всегда настоящая, от Telegram.

## Демо без сервера

`demo/` запускает весь Поток в одной вкладке браузера: код воркера из `src/`
работает прямо на странице поверх SQLite, собранного в JavaScript (sql.js).
Приложение ходит в `/api/*` как обычно, но запросы уходят в этот код, а не
в сеть. Подпись Telegram настоящая, только с демонстрационным ключом.
Лента заполнена, а на ваши посты и комментарии через несколько секунд
отвечают персонажи, так что уведомления видно в деле. Всё живёт до
перезагрузки.

`demo/page.html` — страница без обёртки документа (её добавляет публикация
артефактом). Запустить у себя можно так: положить её рядом с `public/`,
`src/`, `demo/` и `schema.sql`, обернуть в `<html><body>…</body></html>` и
открыть через любой статический сервер.
