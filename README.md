# Поток — студенческая соцсеть МГУ в Telegram

Мини-приложение Telegram. У каждого факультета своя лента, и есть общая лента
всего университета. Вход через Telegram, регистрации нет.

## Что внутри

| Что | Зачем заходить каждый день |
| --- | --- |
| **Лента факультета и всего МГУ** | Переключатель сверху; новое и «горячее» (лайки и комментарии, делённые на возраст поста) |
| **Рубрики** | Общее · Учёба · Подслушано · События · Барахолка · Бюро находок · Жильё |
| **Подслушано** | Всегда анонимно. В комментариях — «Аноним 1», «Аноним 2»: один человек под одним номером внутри поста, автор помечен |
| **События** | Дата и место, отдельная сортировка «скоро»; ближайшие события МГУ на вкладке поиска |
| **Барахолка, находки, жильё** | Цена или «Даром», отметка «продано / нашлось» — пост гаснет, но остаётся |
| **Фото и опросы** | До 6 фото, сжатие на телефоне до ~300 КБ; опрос до 6 вариантов, один голос |
| **Комментарии** | Ответ цитатой, как в Telegram; анонимный режим — кнопка с маской |
| **Уведомления** | Вкладка «Ответы» со счётчиком и сообщение от бота с кнопкой «Открыть» |
| **Профиль** | Факультет, курс, о себе; «Написать в Telegram», если человек не скрыл ник |
| **Поиск** | Люди и посты, без учёта регистра и «ё» |
| **Поделиться** | Ссылка вида `t.me/бот/приложение?startapp=p12` сразу открывает пост |

## Из чего состоит

| Что | Где |
| --- | --- |
| Страница приложения — HTML, CSS и JS-модули без сборки | `public/` |
| API, бот и фото — один Cloudflare Worker | `src/` |
| Схема базы D1 | `schema.sql` |
| Сквозная проверка API | `tests/smoke.mjs` |
| Подпись initData для локальной работы, наполнение базы | `tools/` |

Воркер раздаёт и страницу (папку `public` через assets), и API на том же
адресе. Одна команда `npx wrangler deploy` выкладывает всё, CORS не нужен.

- `/api/*` — API, каждый запрос подписан Telegram (`Authorization: tma <initData>`).
- `/img/*` — фото из R2, кэшируются навсегда: имя файла случайное и не меняется.
- `/tg` — вебхук бота.

Справочники факультетов, рубрик и лимитов лежат в `public/js/data.js`. Этот файл
импортирует и приложение, и воркер, поэтому список на экране и проверка на
сервере не могут разойтись.

## Первый запуск в бою

Нужен аккаунт Cloudflare (бесплатного тарифа хватает) и бот от @BotFather.

```bash
npm install

# 1. База и хранилище фото
npx wrangler d1 create potok          # id из вывода — в wrangler.toml, database_id
npm run db:remote                     # создать таблицы
npx wrangler r2 bucket create potok-media

# 2. Секреты: токен бота и секрет вебхука (любая длинная случайная строка)
npx wrangler secret put BOT_TOKEN
npx wrangler secret put WEBHOOK_SECRET

# 3. Выложить
npm run deploy                        # напечатает адрес вида https://potok.<вы>.workers.dev
```

R2 включается один раз в панели Cloudflare (**R2 → Enable**). Для этого
Cloudflare попросит привязать карту, но в пределах 10 ГБ хранение бесплатное.

Дальше в `wrangler.toml`, раздел `[vars]`:

- `ADMIN_IDS` — ваш id в Telegram (его покажет @userinfobot). Можно несколько через запятую.
- `BOT_USERNAME` — имя бота без @.
- `APP_NAME` — короткое имя приложения из шага 5.

После правки ещё раз выполните `npm run deploy`.

### Бот

4. Вебхук (подставить токен, адрес воркера и тот же секрет):

   ```bash
   curl "https://api.telegram.org/bot<ТОКЕН>/setWebhook" \
     -d url=https://potok.<вы>.workers.dev/tg \
     -d secret_token=<WEBHOOK_SECRET> \
     -d 'allowed_updates=["message","callback_query","my_chat_member"]'
   ```

   Без секрета воркер отвечает 403: иначе кто угодно мог бы прислать ему
   поддельное «нажатие» кнопки модератора.

5. В @BotFather:
   - `/newapp` → выбрать бота → адрес воркера → короткое имя, например `app`.
     Оно нужно для ссылок «поделиться» (`t.me/бот/app?startapp=p12`).
   - `/setmenubutton` → адрес воркера → «Поток». Кнопка слева от поля ввода
     открывает приложение.

## Модерация

Вся модерация идёт в личке с ботом. Команды принимаются только от `ADMIN_IDS`.

- **Три жалобы от разных людей** скрывают пост или комментарий. Модераторам
  приходит карточка: текст, автор (даже анонимный), причины жалоб. На ней
  кнопки «Вернуть», «Удалить», «Удалить и бан на 7 дней». Решение дописывается
  в карточку, чтобы второй модератор не взялся за уже разобранное.
- `/hidden` — всё, что сейчас скрыто жалобами.
- `/who p12` · `/who c34` — карточка поста или комментария с кнопками.
- `/del p12` · `/restore p12` — удалить или вернуть.
- `/ban №5 7 спам` — бан на 7 дней с причиной; без числа — навсегда.
  Человека можно указать как `№5`, `@ник` или `p12` (автор поста).
- `/unban №5` · `/stats` — сводка за сутки и неделю.

Модератор в самом приложении видит у чужих постов и комментариев пункт
«Удалить (модератор)».

**Анонимность.** Автор анонимного поста или комментария вообще не покидает
воркер: в ответах API нет ни имени, ни id, ни намёка в счётчиках профиля.
Узнать автора может только модератор через бота, и только когда нужно
разобрать жалобу.

## Лимиты

| Что | Сколько |
| --- | --- |
| Посты | 15 в сутки, из них анонимных — 5 |
| Комментарии | 150 в сутки |
| Жалобы | 30 в сутки |
| Фото | 60 загрузок в сутки, до 6 на пост, до 3 МБ |
| Уведомления от бота | не чаще раза в 5 минут; остальное видно на вкладке «Ответы» |

Лимиты записаны в начале `src/posts.js`, `src/comments.js`, `src/media.js`,
`src/moderation.js` и `src/notify.js`.

## Разработка

```bash
cp .dev.vars.example .dev.vars   # тестовый токен, секрет, ADMIN_IDS
npm run db:local                 # таблицы в локальной базе
npm run dev                      # http://127.0.0.1:8787
```

В другом окне:

```bash
node tools/seed.mjs              # 6 человек, 8 постов, лайки, опрос, комментарии
npm run smoke                    # 18 сквозных проверок API
```

Вне Telegram приложению нужна подписанная строка входа. Её печатает
`node tools/sign.mjs 9001 Аня`. Откройте
`http://127.0.0.1:8787/#dev=<строка>`, и вы войдёте как Аня из
`tools/seed.mjs`. Такая подстановка работает только на localhost; в бою
подпись всегда настоящая, от Telegram.

## Демо без сервера

`demo/` запускает весь Поток в одной вкладке браузера: код воркера из `src/`
работает прямо на странице поверх SQLite, собранного в JavaScript (sql.js).
Приложение ходит в `/api/*` как обычно, но запросы уходят в этот код, а не
в сеть. Подпись Telegram настоящая, только с демонстрационным ключом.
Лента заполнена, а на ваши посты и комментарии через несколько секунд
отвечают персонажи, так что уведомления видно в деле. Всё живёт до
перезагрузки.

`demo/page.html` — страница без обёртки документа (её добавляет публикация
артефактом). Запустить у себя можно так: положить её рядом с `public/`,
`src/`, `demo/` и `schema.sql`, обернуть в `<html><body>…</body></html>` и
открыть через любой статический сервер.
